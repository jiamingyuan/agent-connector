# agent-connector 规则

只收用户已确认、持续约束本项目后续变化的原则或边界，并注明来源；功能、配置与部署的现状见 [README](../README.md) 与[项目简介](project-brief.md)，候选建议、临时取舍与任务授权不放这里。

1. **新功能同时覆盖所有已有模块，并测试。** 每新增一个功能，要在所有已有的 Agent 模块和渠道模块里同时开发，并做测试；不能只做当前在用的那一个。
   - README 的“功能与模块”一节用表格列出每个功能在每个模块上的状态：**已完成**（开发完并在真实环境测试通过）、**已开发**（开发完，未在真实环境测试通过）、**未开发**。功能或模块有变化时同步更新这张表。
   - 来源：用户 2026-11-12（飞书）：“做一个项目级的规则吧，每次新增一个功能，同时开发所有存量模块，并测试；在readme里加个功能模块（已有则改造）通过表格形式展示功能和模块测试情况，测试过了就写已完成，开发完就写已开发，未开发的就写未开发”。
